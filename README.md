# 時代華語1 完課測驗（團班版）

這個資料夾放在 GitHub Pages 上，學生用連結做測驗，成績自動寫進老師的 Google 試算表。

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 課程目錄（16 課） |
| `L01.html` ～ `L16.html` | 每一課的完課測驗 |
| `config.js` | **要改的地方**：貼上 Apps Script 網址、預設班級 |
| `apps-script/Code.gs` | 貼到 Google Apps Script 的程式（收成績用） |

## 第一次設定（大約 10 分鐘）
1. **開一個新的 Google 試算表**，名字例如「時代華語1 成績」。
2. 試算表上方選單：**擴充功能 → Apps Script**，把裡面的程式全部刪掉，貼上 `apps-script/Code.gs` 的內容，按儲存。
3. 右上角 **部署 → 新增部署作業**：類型選「網頁應用程式」，執行身分「我」，存取權「所有人」，按部署並授權。
4. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。
5. 打開 `config.js`，把 `PASTE_YOUR_APPS_SCRIPT_URL_HERE` 換成剛剛的網址。也可以填 `DEFAULT_CLASS`。
6. 把整個資料夾上傳到 GitHub 的 repo（例如 `shidai1-quiz`），到 **Settings → Pages**，Source 選 `main` 分支、`/ (root)`，存檔。
7. 幾分鐘後網址會是 `https://你的帳號.github.io/shidai1-quiz/`，把這個連結（或 `…/L05.html` 這種單課連結）給學生。

> 如果你想沿用時代華語2的成績試算表：可以直接把時代華語2用的 Apps Script 網址貼到 `config.js`。時代華語1 送出的課號是 `B1-L01`、`B1-L02`……，不會跟時代華語2 的 `L01` 混在一起。不過如果那份舊程式是依照固定欄位寫的，建議還是用這裡新的 `Code.gs` 另開一份試算表。

## 老師看到的成績
- **成績總表**：每次交卷一行——時間、課、班級、座號、姓名、第幾次、分數、百分比、作答分鐘、離開畫面次數、重新整理次數、中途回目錄次數、各部分分數、錯題。
- **B1-L01、B1-L02……**：每一課一個分頁，各部分分數分欄列出，方便排序。

## 學生作答的規則（團班版）
- 每個部分只能做一次，做的時候不會顯示對錯。
- 全部做完按「交卷」，成績送出以後才能看答案和說明。
- 如果成績沒送出去（網路問題），畫面會出現「複製」按鈕，學生可以把成績貼給老師。
- 系統會記錄作答時間、離開畫面次數和重新整理次數。

## 題型
- 生詞、語法、排句子（兩個子句的句子有紅色「，」詞卡要排進去）、看圖回答（TOCFL 圖片題）、短文填空
- 量詞：第 3、6、9、12、15 課（每三課複習一次）
- 閱讀理解：第 6 課開始；短文裡畫線的詞是下一課或下兩課的生詞，學生要從上下文猜意思
